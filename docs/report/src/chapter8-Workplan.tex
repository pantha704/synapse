\chapter{Work Plan}

The project runs across two semesters, split into Project-I and Project-II. Each phase has defined deliverables.

\section{Project-I (Semester 1)}

\begin{table}[H]
\centering
\caption{Work Plan for Project-I}
\label{tab:workplan1}
\begin{tabular}{|c|p{7cm}|c|}
\hline
\thead{Month} & \thead{Activity} & \thead{Deliverable} \\ \hline
Month 1 & Review existing LMS platforms and related literature. Finalize system requirements and feature list. & Requirements Document \\ \hline
Month 2 & Design the system architecture and database schema. Set up the Next.js project, Supabase backend, and authentication flow. & Architecture Design \\ \hline
Month 3 & Build multi-tenant onboarding, role-based access control, and the teacher dashboard for course and batch management. & Admin \& Teacher Modules \\ \hline
Month 4 & Build the React Flow mindmap canvas for curriculum creation. Implement node states and basic progress tracking. & Mindmap Canvas \\ \hline
Month 5 & Build the student dashboard with mindmap view. Implement dual progress tracking and the class progress dashboard. & Student Module \& Analytics \\ \hline
\end{tabular}
\end{table}


\section{Project-II (Semester 2)}

\begin{table}[H]

\caption{Work Plan for Project-II}

\begin{tabular}{|c|p{7cm}|c|}
\hline

Month 3 & Run user testing with a group of students and teachers. Collect feedback on usability and engagement. & User Testing Report \\ \hline
Month 4 & Fix bugs, optimize performance, and finalize documentation. Prepare the final report and presentation. & Final Report \\ \hline
