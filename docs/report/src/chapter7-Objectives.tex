\chapter{Objectives}
\label{Objectives}

\section{Main Objective}

To design and build an interactive, mindmap-based Learning Management System (Synapse) that visually tracks student progress and makes it possible to compare what has been taught with what has actually been learned.

\section{Specific Objectives}

\begin{enumerate}
    \item \textbf{To study} existing LMS platforms and identify where they fall short in progress visualization, student engagement, and learning analytics.

    \item \textbf{To design} a mindmap-based interface where the course syllabus is shown as a node graph, with each node representing a topic and reflecting its current state (not started, upcoming, in progress, completed).

    \item \textbf{To implement} dual progress tracking that places the teacher's delivery timeline alongside each student's actual progress, with the gap between them surfaced as a per-student engagement band and a list of topics the class has not started.

    \item \textbf{To develop} an AI study assistant using Retrieval-Augmented Generation (RAG) that answers questions using only the teacher's uploaded course materials, avoiding hallucinated or off-topic responses.

    \item \textbf{To build} a multi-tenant architecture with Row-Level Security (RLS) so that multiple institutions can share the same platform while their data stays completely separate.

    \item \textbf{To evaluate} the system through user testing with students and teachers, measuring whether it improves engagement, progress awareness, and early detection of students who are falling behind.
\end{enumerate}
