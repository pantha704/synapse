\chapter{Objectives}
\label{Objectives}

\section{Main Objective}

To design and build an interactive, mindmap-based Learning Management System, Synapse, that shows student progress visually and lets a teacher compare what has been taught with what has actually been learned.

\section{Specific Objectives}

\begin{enumerate}
    \item \textbf{To study} existing LMS platforms and name, concretely, where they fall short on progress visualisation, engagement and analytics.

    \item \textbf{To design} an interface in which the syllabus is a node graph, each node a topic, and each node's appearance reflects its state: not started, in progress, completed, with upcoming derived on the path view.

    \item \textbf{To implement} dual progress tracking that holds the teacher's delivery timeline beside each student's position, surfacing the difference as a per-student band and a list of released but unstarted topics.

    \item \textbf{To develop} a retrieval-augmented study assistant that answers only from the teacher's uploaded material, and refuses a question the material cannot support instead of inventing an answer.

    \item \textbf{To build} a multi-tenant architecture in which Row-Level Security and explicit tenant predicates keep institutions apart on one deployment, verified by probes instead of by assertion.

    \item \textbf{To evaluate} the result through a demo with students and teachers, asking whether the map improves awareness of progress and whether the class view helps a teacher spot a struggling student earlier than a grade sheet would.
\end{enumerate}
