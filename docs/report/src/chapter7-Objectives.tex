\chapter{Objectives}
\label{Objectives}

\section{Main Objective}

To design and implement an interactive, mindmap-based learning management system that represents student progress visually and permits comparison between the material taught and the material learned.

\section{Specific Objectives}

\begin{enumerate}
    \item \textbf{To examine} existing learning management systems and identify their limitations in progress visualisation, student engagement and learning analytics.

    \item \textbf{To design} an interface in which the syllabus is represented as a node graph, each node corresponding to a topic and presenting its current state, namely not started, in progress or completed, with the upcoming state derived in the learning-path view.

    \item \textbf{To implement} dual progress tracking that records the teacher's delivery and each student's position separately, and presents the difference as an engagement classification and a list of released but unstarted topics.

    \item \textbf{To develop} a retrieval-augmented assistant that answers only from material supplied for the subject and declines to answer where the material does not support a response.

    \item \textbf{To construct} a multi-tenant architecture in which row-level policies and explicit tenant predicates separate institutions within one deployment, verified by database probes.

    \item \textbf{To evaluate} the implementation with students and teachers, considering whether the map improves awareness of progress and whether the class view allows a student requiring support to be identified earlier than a gradebook allows.
\end{enumerate}
